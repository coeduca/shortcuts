# Shortcuts · Mi espacio

Webapp estática para organizar accesos rápidos por categorías. Funciona sin
servidor y guarda los cambios en el navegador.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube todos los archivos de esta carpeta.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main`, la carpeta `/ (root)` y guarda.

No necesita compilación ni dependencias.

## Funciones

- Pestañas personalizables y reordenables.
- Crear, editar, eliminar y reordenar atajos.
- Favoritos, búsqueda y modo claro/oscuro.
- Respaldo e importación de datos.
- Diseño adaptable para computadora, tableta y móvil.

Los datos se guardan con `localStorage`, por lo que cada navegador conserva su
propia organización.
